# Практична робота №1

**Тема:** Розробка програмних модулів з використанням базових операторів, умовних конструкцій та циклів у Python.

## Мета роботи

Закріпити навички програмування мовою Python, навчитися використовувати математичні оператори, перетворювати типи даних, працювати з умовними конструкціями та циклами, а також створювати прості програми для розв'язання практичних завдань.

## Опис роботи

У ході практичної роботи було створено шість програм мовою Python. Кожна програма демонструє використання базових конструкцій мови, обробку введених даних та виведення результатів.

## Виконані завдання

### Завдання 1.1. Обчислення математичних виразів

Розроблено програму для обчислення математичних виразів із використанням арифметичних операторів Python.

Програма виконує необхідні обчислення та виводить отримані результати.

### Завдання 1.2. Перетворення типів даних

Створено програму для роботи з основними типами даних Python.

Реалізовано перетворення значень між різними типами та перевірено результати виконання відповідних операцій.

### Завдання 2.1. Визначення оцінки за шкалою ЄКТС

Реалізовано програму, яка визначає оцінку за шкалою ЄКТС залежно від введеної кількості балів.

Для перевірки діапазонів оцінювання використано умовні конструкції `if`, `elif` та `else`.

### Завдання 2.2. Визначення типу та площі трикутника

Створено програму для визначення типу трикутника за довжинами його сторін.

Реалізовано перевірку можливості існування трикутника та обчислення його площі за формулою Герона.

### Завдання 3.1. Використання циклів

Розроблено програму для виконання обчислень із використанням циклів `for` та `while`.

Реалізовано обчислення факторіала, суми гармонічного ряду та формування таблиці множення.

### Завдання 3.2. Інтерактивний калькулятор

Створено консольний калькулятор, який виконує основні арифметичні операції.

У програмі реалізовано введення чисел, вибір математичної операції, перевірку ділення на нуль та обробку неправильного введення.

Також додано можливість перегляду історії виконаних обчислень.

## Використані технології

- Python
- Арифметичні оператори
- Умовні конструкції `if`, `elif`, `else`
- Цикли `for` та `while`
- Функції
- Обробка введення та виведення даних

## Запуск програм

Для запуску необхідно встановити Python.

Відкрийте термінал у папці проєкту та виконайте команду:

```powershell
python назва_файлу.py
```

Замість `назва_файлу.py` потрібно вказати назву файлу відповідного завдання.

Програми запускаються через консоль і не потребують додаткових зовнішніх бібліотек.

Перевірено роботу арифметичних операцій, умовних конструкцій, циклів та обробки введених даних. Також реалізовано перевірки некоректного введення в окремих завданнях.
